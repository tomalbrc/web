Projects

Mods

Here are a few of my Minecraft based mods:

  • Toms Mobs: Adds unique mobs to Minecraft that run server-side, without needing client-side mods.
  • Filament: Lets server admins add custom blocks, items, and furniture using data-packs.
  • Blockbench Import Library: Makes it easy to import models and animations from Blockbench into Minecraft for server-side use.
  • Camera Obscura: A serverside mod that lets players render their POV in-game as map items using raycasting.

GitHub Open-Source Projects

Explore my open-source contributions to various creative and technical projects:

  • ProceduralTerrainGeneration: Implements procedural terrain generation in Irrlicht using C++ STL for multithreading. GitHub
  • L-System: A project exploring L-systems for procedural content generation. GitHub
  • PDF-plus: A PDF creation tool written in C++. GitHub
